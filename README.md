# Student Performance Analysis

## Overview
This project analyzes student exam performance data to identify factors affecting academic achievement and detect at-risk students.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Data Visualization
- At-Risk Student Segmentation

## Key Findings
1. Test preparation improves student performance.
2. Higher parental education is associated with better scores.
3. Reading and writing scores have a strong positive correlation.
4. Male students perform better in mathematics.
5. Female students perform better in reading and writing.

## Recommendations
- Expand test preparation programs.
- Support at-risk students through targeted interventions.
- Increase parental engagement.

## Dataset
Students Performance in Exams Dataset (Kaggle)
